# Support

## Free support

Use [GitHub issues](https://github.com/zerodot-io/zerodot/issues) for bug reports, feature requests, and questions. Everyone can use it, and it costs nothing. Bug reports and security reports are never paid-only.

## Paid support

A Support License gives you access to the private Zerodot Discord server and priority help from the maintainer.

|                                 | Free               | Support License |
| ------------------------------- | ------------------ | --------------- |
| GitHub issues                   | Yes                | Yes             |
| Private Discord server          | No                 | Yes             |
| Direct chat with the maintainer | No                 | Yes             |
| Response goal                   | Best effort        | 24-48 hours     |
| Setup and deploy help           | No                 | Yes             |
| Vote on the roadmap             | Public issues only | Private channel |

Price and checkout: `<SUPPORT_LICENSE_URL>`

The [Support License terms](SUPPORT-LICENSE.md) explain what you get and what you do not get.

## What a Support License does not change

Zerodot stays free software under AGPL-3.0-only. A Support License is not a software license. It does not give you any rights to the code, and it does not remove any duty in the AGPL. It pays for the maintainer's time.
