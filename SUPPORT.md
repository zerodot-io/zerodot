# Support

## Free support

Use [GitHub issues](https://github.com/zerodot-io/zerodot/issues) for bug reports, feature requests, and questions. Everyone can use it, and it costs nothing. Bug reports and security reports are never paid-only.

## Community Access

Community Access is a digital product. It gives you access to the private Zerodot community Discord server and a private channel to vote on the roadmap. Each Commercial License includes it, and you also get a Discord role for your license type (Hobby, Team, Organization, or Extended).

|                        | Free               | Community Access |
| ---------------------- | ------------------ | ---------------- |
| GitHub issues          | Yes                | Yes              |
| Private Discord server | No                 | Yes              |
| Vote on the roadmap    | Public issues only | Private channel  |

Price and checkout: `<COMMUNITY_ACCESS_URL>`

Community Access does not include setup, deployment, or technical support. It does not include direct help from the maintainer. It does not include a response time. The [Community Access terms](SUPPORT-LICENSE.md) explain what you get and what you do not get.

## What Community Access does not change

Zerodot stays free software under AGPL-3.0-only. To keep your changes private, buy a [Commercial License](COMMERCIAL-LICENSE.md). Every Commercial License includes Community Access. Community Access is not a software license. It does not give you any rights to the code, and it does not remove any duty in the AGPL.
