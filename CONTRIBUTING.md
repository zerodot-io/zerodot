# Contributing

Thank you for your help. Read the "Develop" section in the [README](README.md) to run Zerodot on your computer.

## Contributor License Agreement

You must sign the [Contributor License Agreement](CLA.md) before we can merge your pull request. You keep the copyright in your work. The agreement lets 7 Angle, the owner and maintainer of Zerodot, distribute Zerodot under other licenses, in addition to AGPL-3.0-only.

To sign, add this comment to your first pull request:

```
I have read the CLA Document and I hereby sign the CLA
```

The CLA bot checks the pull request. You sign one time. The signature covers all your later pull requests.

## Pull requests

1. Make a branch named `feat/<name>`, `fix/<name>`, or `chore/<name>`.
2. Run `pnpm run check-types`, `pnpm run lint`, and `pnpm run test`. The pre-commit hook runs the first two.
3. Keep each pull request small and on one topic.
4. Describe what changed and why.

## Questions and bugs

Use [GitHub issues](https://github.com/zerodot-io/zerodot/issues) for bug reports and feature requests. This is free for everyone. For paid support, read [SUPPORT.md](SUPPORT.md).
